## 🧪 Featured Research & Projects

### 🐾 [TrapSense AI](https://github.com/sandep962) — Wildlife Intelligence
* **Innovation:** Automated species classification in camera trap data to assist conservationists.
* **Architecture:** Scalable pipeline using **YOLOv8** and **FastAPI**, deployed via **AWS S3** for large-scale image processing.

### 🛡️ [Guardian AI](https://github.com/sandep962) — Real-time Security
* **Innovation:** Detection of verbal threats in live audio streams.
* **Architecture:** Multi-modal approach combining **Whisper (STT)** and **BERT** for intent analysis.
