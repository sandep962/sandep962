## Featured Projects

### 🛰️ Aerial GCP Pose Estimation & Shape Classification

**PyTorch · ResNet18 · Computer Vision · Keypoint Localization**

Developed a multi-task computer vision pipeline to localize Ground Control Points (GCPs) and classify their shapes in aerial drone imagery.

- Curated and preprocessed **996 annotated aerial images**.
- Built a ResNet18-based model for coordinate regression and shape classification.
- Classified three GCP categories: Cross, Square, and L-Shape.
- Combined coordinate regression and cross-entropy classification losses.
- Addressed class imbalance using weighted loss terms.
- Implemented training and validation pipelines with PyTorch DataLoader and AdamW.

**Focus:** Multi-task learning, coordinate normalization, data preprocessing, and model evaluation.

[Explore my repositories →](https://github.com/sandep962)

### 🤖 Multi-Agent AI System

**Python · LLMs · RAG · Agent Orchestration · Tool Calling**

Built a multi-agent AI system that interprets natural-language queries and retrieves relevant information from structured client records.

- Designed agent coordination and query-routing logic.
- Integrated retrieval-augmented techniques to ground responses in available records.

- Tested varied client-record queries for response reliability and consistency.

**Focus:** Agentic workflows, retrieval pipelines, grounded generation, and system reliability.
